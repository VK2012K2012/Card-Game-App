# Research sources

The app-wide Material 3 redesign uses official Material Design and Android guidance. Recommendations for the card-game hub are product-specific applications of those sources, not claims that Material prescribes a card-game template.

| Topic | Official source | Applied in this release |
|---|---|---|
| Material 3 theming, Compose components, typography, shapes, and dynamic color | [Material 3 in Jetpack Compose](https://developer.android.com/develop/ui/compose/designsystems/material3) | Centralized color, type, and shape tokens; native Compose Material controls; wallpaper-derived color on Android 12+ with custom fallback schemes. |
| Material 3 semantic color roles and surface containers | [Material 3 color roles](https://m3.material.io/styles/color/roles) | Matched `on*` foregrounds to container roles, reserved primary/secondary/tertiary for differing emphasis, and used surface-container levels to separate app canvas, library cards, setup, and match information. |
| Material 3 Expressive principles and component guidance | [Material 3 in Compose](https://developer.android.com/develop/ui/compose/designsystems/material3) and [Material 3 Expressive overview](https://m3.material.io/blog/building-with-m3-expressive) | Concentrated distinctive shape, color, and size in the featured game and card-fan art; kept navigation, settings, statistics, and active play calmer and legible. |
| Typography role hierarchy | [Material 3 typography](https://developer.android.com/develop/ui/compose/designsystems/material3) | Used centrally defined display/headline/title/body/label styles and reduced heavy weight on routine labels and descriptions. |
| Shape scale | [Material 3 shape system](https://developer.android.com/develop/ui/compose/designsystems/material3) | Reused the app's shared corner scale, with a larger expressive radius reserved for hero surfaces and bottom sheets. |
| Motion schemes | [Material 3 motion physics system](https://m3.material.io/styles/motion/overview/how-it-works) | Kept the app's expressive motion scheme while limiting additional custom movement; Material notes that expressive motion suits key interactions and hero moments, while utility motion should be restrained. |
| Accessibility semantics and touch targets | [Accessibility API defaults in Compose](https://developer.android.com/develop/ui/compose/accessibility/api-defaults) | Used native Material controls for navigation, setup choices, buttons, sheets, and dialogs; marked the custom decorative card stack as non-semantic; added contrast tests for static schemes. |
| Adaptive Android layouts | [Support different display sizes](https://developer.android.com/develop/adaptive-apps/guides/support-different-display-sizes) | Kept game and library content scrollable and constrained by available layout space where needed; future large-window navigation should be driven by current app-window size. |
| Android memory efficiency | [Android memory efficiency](https://developer.android.com/blog/posts/prioritizing-memory-efficiency-essential-steps-for-android-17) | Release build keeps R8 optimization and resource shrinking enabled. |
| ProfilingManager overview | [ProfilingManager overview](https://developer.android.com/topic/performance/tracing/profiling-manager/overview) | Developer diagnostics remain explicit and version-gated. |
| App-driven profiling | [Capture profiles with the app](https://developer.android.com/topic/performance/tracing/profiling-manager/how-to-capture) | Heap profiles are requested asynchronously, with no automatic collection or upload. |
| Gemini API key security | [Gemini API key guidance](https://ai.google.dev/gemini-api/docs/api-key) | Any future mobile AI integration must keep provider credentials behind a controlled backend rather than embedding them in the APK. |
| Gemini API pricing | [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing) | External model use remains optional; the current build stays offline and makes no model calls. |
| Ready-made game-night palette inspiration | [Media.io green/burgundy palette collection](https://www.media.io/color-palette/green-burgundy-color-palette.html) | Reviewed Modern Library (`#133A2F`, `#5C1E2F`, `#A2A7A1`, `#EFE6D8`, `#C7A35E`), Vineyard Evergreen (`#0F3D2E`, `#6B1F33`, `#8FBFA4`, `#F2E8D5`, `#2A2B2E`), and Autumn Terrace (`#2A6B4F`, `#7B2B3F`, `#D7C9B2`, `#F6F0E6`, `#3F3A34`) as mood/seed references. The app maps these hues into Material 3 roles instead of applying raw colors as text/background pairs. |
| Teal, navy, and antique-gold palette inspiration | [Media.io teal/gold palette collection](https://www.media.io/color-palette/teal-gold-color-palette.html) | Reviewed Museum Velvet (`#0A3D3B`, `#115E59`, `#C9A227`, `#E6DDC6`, `#3F2D20`), Botanical Foil (`#0B6B6B`, `#2EC4B6`, `#C6A15B`, `#EDF6F9`, `#2B2D42`), and Tech Dashboard Luxe (`#064663`, `#0EA5A4`, `#FBBF24`, `#0F172A`, `#E2E8F0`) as contrasting seed references for dark teal, sea-glass, and gold schemes. |
| Burgundy and gold palette inspiration | [Color-hex Burgundy Gold Classic](https://www.color-hex.com/color-palette/108674) | Reviewed its burgundy/red/gold/cream set (`#730000`, `#9B000A`, `#FFBD00`, `#F3EFD0`, `#FFFFFF`); the app derives light/dark role schemes and uses the existing contrast tests. |

The official sources were reviewed on 2026-10-13. Material 3 guidance evolves; check current AndroidX component APIs and Material documentation before adopting newer recommendations.
